Download & Pasang UNUGHA NetWatch

Tersedia untuk semua HP Android, Tablet, iPad, MacBook & PC

Android Universal (HP & Tablet)

Dua Cara Pasang di Smartphone Android:

Kompatibel dengan Android versi 5.0 (Lollipop) hingga Android 15 (Semua merk: Samsung, Xiaomi, Oppo, Vivo, Realme, Infinix, dll)

Opsi 1: Download File APK
UNUGHA-NetWatch.apk

Paket instalasi APK mandiri. Unduh dan buka langsung di pengelola berkas HP.

Unduh Sekarang (.apk)
Petunjuk Pemasangan APK di HP Android:
  1. Ketuk tombol Download File APK di atas.
  2. Jika muncul peringatan "File mungkin berbahaya", pilih Tetap Download (aman resmi dari server UNUGHA).
  3. Buka file hasil unduh dan aktifkan "Izinkan instalasi dari sumber ini".
  4. Tekan Install dan buka aplikasi NetWatch.
Tablet Android & iPadOS

Optimalisasi Layar Lebar Tablet

Mendukung orientasi Landscape & Portrait secara responsif otomatis.

Untuk Apple iPad / iPadOS:

1. Buka aplikasi di peramban Safari.

2. Ketuk ikon Bagikan (Share) di bagian atas.

3. Gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).

4. Aplikasi siap digunakan seperti aplikasi iPad bawaan.

Untuk Tablet Android:

1. Buka di Google Chrome pada tablet Anda.

2. Ketuk menu titik tiga (⋮) di pojok kanan atas.

3. Pilih "Install Aplikasi" atau "Tambahkan ke Layar Utama".

4. Atau unduh file APK langsung melalui tab Android.

macOS (MacBook, iMac, Mac Mini)

Instalasi Aplikasi Mandiri di macOS

Kompatibel dengan semua macOS (Sonoma, Ventura, Monterey, Big Sur) chip Apple Silicon (M1/M2/M3/M4) & Intel.

Metode 1: Apple Safari (macOS Sonoma+)

1. Buka web NetWatch di Safari.

2. Klik menu File di menu bar atas Mac.

3. Pilih "Tambahkan ke Dock..." (Add to Dock).

4. NetWatch kini menjadi aplikasi native mandiri di Dock Mac Anda.

Metode 2: Google Chrome / Edge macOS

1. Buka di Google Chrome pada MacBook Anda.

2. Klik ikon Install (simbol monitor kecil berpanah bawah) di ujung kanan address bar.

3. Klik Install pada jendela konfirmasi.

4. Aplikasi akan otomatis tersimpan di folder Applications Mac.

Windows 10 & 11 PC / Laptop

Aplikasi Desktop Windows Mandiri

Bisa dijalankan tanpa membuka browser terlebih dahulu, dapat disematkan di Taskbar.

1. Buka di Microsoft Edge atau Google Chrome.

2. Klik ikon Install App pada bilah alamat URL atas.

3. Centang "Pin to taskbar" dan "Create Desktop shortcut".

4. UNUGHA NetWatch siap dibuka langsung dari desktop Windows.

Scan dari Kamera HP / Tablet

Arahkan kamera smartphone ke QR Code ini untuk langsung membuka dan memasang NetWatch di perangkat Anda.
